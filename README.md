# SMART HOME SECURITY

## 1. Giới thiệu
Xây dựng hệ thống giám sát an ninh nhà ở thông minh ứng dụng công nghệ nhận diện khuôn mặt và cảnh báo người lạ.

## 2. Mục tiêu
- Phát hiện khuôn mặt từ camera IP.
- Nhận diện thành viên gia đình đã đăng ký.
- Phát hiện và ghi nhận khuôn mặt chưa nhận diện.
- Gửi cảnh báo đến điện thoại khi phát hiện người chưa nhận diện.
- Xây dựng website quản lý và giám sát hệ thống.

## 3. Công nghệ dự kiến
- Python 3.11
- OpenCV
- InsightFace
- ONNX Runtime
- FastAPI
- SQLite
- HTML, CSS, JavaScript
- Git và GitHub

## 4. Trạng thái
Đang trong giai đoạn xây dựng và phát triển.

## 5. Lưu ý
Dữ liệu khuôn mặt, ảnh camera, thông tin đăng nhập và dữ liệu riêng tư không được công khai trên GitHub.
